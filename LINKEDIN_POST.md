🎬 Introducing StreamPick: A Smarter Way to Find Your Next Favorite Show

Ever spent 30 minutes scrolling through Netflix, Hulu, or Prime Video only to give up and rewatch The Office for the 10th time? I built something to fix that.

**What I Built:**
StreamPick is an intelligent recommendation engine that goes beyond the basic "because you watched X" algorithm. Instead of relying on a single data source, it combines multiple signals to find truly great content:

✅ 25% Critics Score (Rotten Tomatoes, Metacritic)
✅ 25% User Ratings (IMDb, TMDb)
✅ 20% Social Trends (Reddit discussions)
✅ 30% Your Personal Taste (genre preferences + viewing history)

**Why This Matters:**
Traditional streaming recommendations often create filter bubbles, showing you only what you've already watched. StreamPick's diversity algorithm ensures variety:
- Maximum 5 items per genre
- Balanced across 8 streaming platforms
- No duplicate recommendations for 30 days
- Discovers hidden gems alongside popular hits

**The Tech Stack:**
- Frontend: React 18 + Vite, Tailwind CSS, React Query
- Backend: Node.js + Express, PostgreSQL, Redis
- External APIs: TMDb, Watchmode, OMDb, Reddit
- Multi-source weighted scoring algorithm

**Supported Platforms:**
Netflix • Hulu • Prime Video • Max • Disney+ • Paramount+ • Showtime • Peacock

**The MVP Approach:**
Rather than spending months building the "perfect" solution, I shipped an MVP in [X days/weeks] to validate the concept. The core algorithm works, users can rate content, and the recommendations are genuinely useful.

**What I Learned:**
1. API rate limits force you to be creative with caching strategies
2. Diversity in recommendations is harder than it seems
3. Sometimes the simplest algorithm (weighted averages) beats complex ML
4. Users want quality over quantity - 20 great recommendations beat 100 mediocre ones
